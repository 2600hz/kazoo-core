## SUP-able functions

| Function   | Arguments  | Description                                                                      |
|------------|------------|----------------------------------------------------------------------------------|
| `flush/0`  |            | Flush the cached CNAM dips                                                       |
| `flush/1`  | `(Number)` | Flush the cached CNAM for a given number                                         |
| `info/0`   |            | Print out the node's CNAM settings                                               |
| `lookup/1` | `(Number)` | Create a CNAM request for a given number and print the CID Name returned, if any |
