# Temporal Routes

Temporal routes, also known as time of day routing, are ways of encoding conditional logic based on the current date and time.

A simple example would be to create a rule that between 8:00 and 17:00, Monday through Friday, calls to the main number should ring the front desk; otherwise go straight to voicemail.

More complicated rules are possible; basically whatever can be done in most calendering apps for events can be encoded as temporal rules.
